# Setup prompt

Ask your local coding agent:

> Set up local Android feature evaluation for this project and my current agent client. Reuse working tools and configuration; install only what is missing.
>
> 1. Install Android CLI and its skills using the [official instructions](https://developer.android.com/tools/agents/android-cli).
> 2. Set up ARTEMIS and its MCP connection using the [official instructions](https://github.com/google/artemis#quick-start).
> 3. Check the project's JDK/SDK, connected device or emulator, skill discovery and ARTEMIS diagnostics. Report what is ready and what needs my action.
>
> Keep credentials local and existing settings intact. Ask me to enter keys locally, reload the client or authorize USB debugging when necessary. This is setup only; do not run an evaluation.
